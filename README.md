# CrowMap
> "CrowUtils- but not abysmally terrible!"

It's actually a completely new mod, since CrowUtils was a joke of a codebase (this one isn't much better!)

Kudos to the Wispforest team, owo-lib is singlehandedly carrying this project.

---

**Usage:**
- To place a in-world display, type out `[CrowMap]` on any sign of your choosing, then press the `~` key (at the top-left of your keyboard, below escape) to specify where the map should be placed.
- 
- To select a position to jump to hyperspace to, right click on the in-world map or the map screen and select Jump. **This will not automatically add a route for you if you are not in the same system.**
- 
- To hide the display without moving it, the bind is `[` by default.
- Showing/Hiding the HUD Map is bound to `]` by default.
- The World Map Screen is bound to `X` by default.
- 
- The config menu is somewhat infdev, and can be accessed with the command `/owo-config crowmap`. It can be used to fine-tune the anchor position (e.g. align it to blocks, precise offsets), move the corner of the screen the HUD Map attaches to, and change the size of said map.
